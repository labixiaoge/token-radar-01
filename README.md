# Token Launch Radar

A watchlist of DeFi protocols that have **no token yet**, ranked by implied
launch value: **TVL × category median market-cap / TVL**, clamped to
[0.05, 2.0]. Each row also carries a concrete farming plan in case the
protocol ever launches a token.

Built for the make.fun bounty **"Build the best token launch radar"**
(`token-radar-01`) by [xiaoge-labi](https://make.fun/u/xiaoge-labi).
Join make.fun with my referral link: https://make.fun/r/j11gmnzr

## How it works

`main.ts` reads the competition's sealed DefiLlama snapshot
(`input/snapshot.json`, as of 2026-11-14: 758 protocols, 40 on the watchlist,
floor $50M TVL). A protocol is pre-token when its snapshot entry records no
token (no market cap, no CoinGecko id, no symbol). The board covers the whole
40-protocol watchlist, plus up to 160 early pre-token protocols below the
floor, ranked by TVL. Each row's implied value is TVL × its category's median
mcap/TVL ratio (from `category_ratios.json`); categories without a measured
median use the global median of 0.308. Every row carries a 6-step farming
plan.

## Run it

Requires Node.js 22 or later. No dependencies to install.

```sh
node main.ts --input input/snapshot.json --output out
```

This writes `out/board.json` (`{"rows": [...]}` — 200 rows), `out/data.js`,
copies `dashboard/` and `screenshots/` to `out/`, and writes
`out/dossier.json` last, generated by the vendored `vendor/makefun-board.ts`
(makefun/dossier/v1). Then open `out/dashboard/index.html` in a browser —
the dashboard is fully static and makes no network requests. Click a row for
the protocol detail view and farming plan; use the search box and the
category / chain filters to narrow the board. Click a column header to sort.

## Files

- `main.ts` — the entrypoint: parse the sealed snapshot, rank, write outputs
- `input/snapshot.json` — the sealed DefiLlama snapshot (2026-11-14)
- `vendor/makefun-board.ts` — the make.fun dossier library, vendored verbatim
- `category_ratios.json` — category median mcap/TVL ratios
- `dashboard/index.html`, `dashboard/app.css`, `dashboard/app.js` — the static dashboard
- `screenshots/` — `1-board.png`, `2-detail.png`, `3-filtered.png` (1280×800)
